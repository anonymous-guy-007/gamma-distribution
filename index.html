Interactive Gamma Distribution

Adjust the shape parameter α and scale parameter β to see how the Gamma distribution changes.

Density: f(x) = 1 / (Γ(α)βα) · xα−1 e−x/β, x > 0

The x-axis stays fixed over broad parameter ranges and expands only when necessary, making horizontal shifts of the distribution easier to recognize.
